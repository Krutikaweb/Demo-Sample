## Run locally

Prerequisites:
- Node.js >= 16 (if your project uses Node)

Quick start:

```bash
git clone https://github.com/Krutikaweb/Demo-Sample.git
cd Demo-Sample
# install dependencies (if applicable)
npm install
# run the dev server
npm start
```

If your project is static (plain HTML/CSS), simply open `index.html` in a browser or serve it with a static server.

## Build & Deploy

Example (adjust for your stack):

```bash
npm run build
# then deploy the `dist` or `build` folder to your hosting provider
```

GitHub Pages (recommended for static demos):
1. In the repository Settings → Pages, set the source to the branch and folder you want to publish (for example `main` / root or the `gh-pages` branch).
2. Save and wait a minute or two for the first deployment. The published URL will be:
   https://Krutikaweb.github.io/Demo-Sample/

Tip: You can add a GitHub Actions workflow to auto-deploy on push to the chosen branch.
